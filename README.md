# Dark Lantern (@TheDarkLanternn) — Official Production Repository

Automated production workspace for **Dark Lantern** (`@TheDarkLanternn`), a YouTube Shorts and documentary channel exploring verified historical mysteries, eerie natural phenomena, and dark scientific enigmas.

---

## Brand & Visual Identity
- **Visual Style**: Authentic **layered cut-paper craft diorama** illustration (torn paper fibers, visible depth shadows, warm amber `#f59e0b` lighting on deep matte midnight `#070a10`).
- **Audio Design**: Deep measured voiceover (Landon / Ryan) + `50–52Hz` sub-bass dark room-tone drone + procedural Foley (`tick`, `sub`, `whoosh`, `pop`, `chime`). Zero background music.
- **Standards**: 100% verified real facts (USGS, NASA, peer-reviewed journals). No gore or graphic violence.

---

## Directory Structure
- `.agents/rules/style.md`: Core brand guardrails and visual style constraints.
- `DL01` – `DL16`: Complete production packs for each episode (scripts, Flow prompts, voiceover assets, upload packs, and metadata).
- Channel branding banners and profile avatars.
